# Задание 1 LibraryManager

`dict` (books_by_id) выбран для хранения книг по ключу id. Это позволяет выполнять поиск, проверку существования и удаление за O(1).

`list` (journal) хранит журнал событий в виде tuple (book_id, action). Здесь важен порядок записей, а не уникальность, и допускаются повторные события об одной книге (issued - returned - issued).

`tuple` используется вместо класса Book как фиксированная структура (id, book_name, author, year). Поля не меняются после создания.

`set` (issued_books) хранит id выданных книг. Здесь важна только уникальность факта выдачи (повторно выдать нельзя) и быстрая проверка наличия.
